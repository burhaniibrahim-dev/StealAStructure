# ThrowAnEgg

This is a winter-themed Roblox PvP simulator where players throw eggs to claim structures scattered across one shared map, keep those structures alive by feeding them more eggs, and steal structures from each other. It is built solo, with a public soft launch planned for November 2026.


You start with a handful of eggs and one shaky house. Twenty minutes later you are the player everyone watches: one throw cracks a structure that takes a newcomer ten, your side panel is full of high-level properties, and you are deciding whether to defend what you have or raid the player who just claimed something better.
